# Smart Fitout

Mobile-first home and office maintenance services platform for Udupi.

## Planned features
- Customer service browsing and service-area support
- Request form and request status tracking
- WhatsApp and call actions
- Professional/service management
- Admin dashboard
- Supabase backend with secure Row Level Security (RLS)
